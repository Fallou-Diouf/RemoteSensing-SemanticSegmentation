# Remote Sensing Semantic Segmentation

Semantic segmentation of remote sensing images using a CNN-based Hypercolumns architecture and the Vaihingen dataset.

## Overview

This project implements a semantic segmentation pipeline for remote sensing images. The objective is to assign a semantic class to every pixel of an aerial image.

The project is based on the **Vaihingen dataset** and uses a **Hypercolumns** architecture implemented with PyTorch.

The complete pipeline covers:

- Dataset preparation and patch extraction
- CNN-based semantic segmentation
- Model training
- Quantitative evaluation
- IoU and mIoU computation
- Qualitative visualization of predictions

## Dataset

The project uses the **Vaihingen remote sensing dataset**.

The dataset contains aerial images and corresponding ground-truth segmentation maps.

The data is divided into three splits:

| Split | Image IDs |
|---|---|
| Train | 1, 3, 5, 7, 11, 13, 15, 17, 21, 23, 26 |
| Validation | 28, 30, 32, 34, 37 |
| Test | 2, 4, 6, 8, 10, 12, 14, 16, 20, 22, 24, 27, 29, 31, 33, 35, 38 |

Large images are divided into **512 × 512 patches** with 50% overlap.

The dataset is not included in this repository.

## Method

### Hypercolumns

The model extracts feature maps at different levels of the CNN and upsamples them to the original spatial resolution.

These feature maps are then concatenated with the original input image to form a **hypercolumn representation**.

The resulting representation is processed by a small convolutional MLP to produce a prediction for each pixel.

### Architecture

```text
Input RGB image
      │
      ▼
   Conv1
      │
     Pool
      │
      ▼
   Conv2
      │
     Pool
      │
      ▼
   Conv3
      │
     Pool
      │
      ▼
   Conv4
      │
      │
      ├──────────────┐
      ├── Upsample ──┤
      ├── Upsample ──┤
      ├── Upsample ──┤
      └── Upsample ──┤
                     ▼
              Hypercolumn
                     │
                  MLP1
                     │
                  MLP2
                     │
                  MLP3
                     │
                     ▼
             6-class prediction
```

The network produces an output of:

```text
[B, 6, 512, 512]
```

where each pixel receives scores for the 6 semantic classes.

- **Optimizer:** Adam
- **Learning rate:** 0.001
- **Batch size:** 3
- **Loss:** Cross-Entropy Loss

## Experiments and Results

Two training experiments were performed to study the effect of the number of training epochs.

### V1 — Baseline

The first experiment was trained for **2 epochs**.

| Metric | Result |
|---|---:|
| Pixel Accuracy | 62.53% |
| Mean IoU | 29.90% |

The model did not predict classes 4 and 5 during this experiment.

### V2 — Extended Training

The second experiment used the same architecture and training configuration but was trained for **10 epochs**.

| Metric | V1 — 2 epochs | V2 — 10 epochs |
|---|---:|---:|
| Pixel Accuracy | 62.53% | **70.88%** |
| Class 0 IoU | 51.36% | **56.81%** |
| Class 1 IoU | 35.54% | **56.57%** |
| Class 2 IoU | 31.79% | **44.62%** |
| Class 3 IoU | 60.73% | **64.25%** |
| Class 4 IoU | 0.00% | **4.13%** |
| Class 5 IoU | 0.00% | **5.86%** |
| **Mean IoU** | **29.90%** | **38.71%** |

Training for 10 epochs improved the Mean IoU from **29.90% to 38.71%**, an increase of **8.81 percentage points**.

The improvement was particularly significant for class 1, whose IoU increased from **35.54% to 56.57%**.

Classes 4 and 5 also started to be predicted, although their IoU remained low.

These results show that the initial 2-epoch experiment was not sufficient for the model to fully learn the segmentation task.

## Installation

Clone the repository:

```bash
git clone https://github.com/Fallou-Diouf/RemoteSensing-SemanticSegmentation.git
cd RemoteSensing-SemanticSegmentation
```

Create a virtual environment:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Install the dependencies:

```bash
pip install -r requirements.txt
```

Place the Vaihingen dataset inside the `data/` directory:

```text
data/
├── top/
└── 1CGT/
```

## Usage

Run the complete pipeline with a single command:

```bash
python src/run.py
```

This automatically performs:

1. Model training
2. Model evaluation
3. Inference and prediction visualization

The evaluation computes:

- Pixel Accuracy
- Confusion Matrix
- IoU for each class
- Mean IoU

The prediction visualization is saved in:

```text
results/figures/segmentation_prediction.png
```
